# Session 15 - Layout Mini Project

## Goal

- Combine the Week 3 layout skills into one small Flutter screen.
- Practice `Column`, `Row`, `Padding`, `SizedBox`, `Expanded`, `ListView`, and `GridView`.
- Choose the right scrollable widget for each part of the UI.
- Build from simple data instead of hard-coding every repeated widget.

## Mini Project Idea

Build a beginner learning dashboard screen.

The screen should show:

- an app bar titled `Session 15 Mini Project`
- a header section with a title and short subtitle
- a small stats row using `Row` and `Expanded`
- a category grid using `GridView.builder`
- a recent lessons list using `ListView.builder`

## Skills Reviewed

- `Column` for vertical structure
- `Row` for horizontal groups
- `Padding` for space around widgets
- `SizedBox` for fixed gaps
- `Expanded` for scrollable widgets inside a `Column`
- `ListView.builder` for repeated list rows
- `GridView.builder` for repeated grid cards
- model classes for data-driven UI

## What I Need To Understand By The End

- A screen can be built in sections.
- Header and stats can use normal layout widgets.
- Repeated content should come from lists of data.
- `ListView` and `GridView` need clear height when placed inside a `Column`.
- If a screen becomes too complex, smaller widgets can be extracted later.
